STEP 01 / 目的を理解

保存・共有・バックアップは同じではありません。

「ファイルがある」ことと、「ほかの人が使える」ことと、「消えても元に戻せる」こと。必要な機能はそれぞれ違います。

共有・同期とは？

離れたPCや社員同士で同じファイルを使うための仕組み。便利ですが、削除や上書きが別の端末にも反映される場合があります。

PC A資料を編集
↔
共有先変更を同期

バックアップとは？

元データとは別のコピーや履歴を保存し、故障や誤削除のあとに復元できるようにする仕組みです。

元データ日常利用
→
別のコピー復元に使う

重要：クラウドストレージもNASも、設定・契約内容によってはバックアップ機能を備えます。ただし、共有・同期そのものやNASのRAID構成を、独立したバックアップと同一視しないでください。

STEP 02 / 3つの保存方法

どこに保存するかで、得意なことが変わります。

CLOUD STORAGE

クラウドストレージ

インターネット上の事業者が管理する環境にデータを保管。離れた拠点からのアクセス・共同利用がしやすい一方、月額費用や権限・サービス提供条件の確認が必要です。

向いている例

複数拠点・テレワーク・外部パートナーとのファイル共有

購入前：保存容量、ユーザー数、権限管理、利用規約、データ所在
NETWORK ATTACHED STORAGE

NAS

自社や自宅のネットワークに置く共有用の保存機器。機器・HDDの購入、ネットワーク設定、障害対応、バックアップ運用が必要です。

向いている例

大きなファイルを社内で共同利用し、管理担当者がいる環境

購入前：HDD同梱・別売、RAIDによる実効容量、対応ドライブ、保守
EXTERNAL HDD / SSD

外付けHDD・SSD

USBなどでPCに接続するドライブ。ファイルの持ち出しや保存・バックアップ用途に使えますが、1台だけでは物理故障・盗難への備えにならないことがあります。

向いている例

1台のPCから定期的に別の場所へコピーする用途

購入前：容量、接続方式、OS・接続機器との互換性
MULTIPLE LAYERS

組み合わせるという選択

共有をクラウドで行い、独立した方法でバックアップを取るなど、複数の役割を組み合わせる方法もあります。誰もが新しい機器を買う必要はありません。

向いている例

業務停止やデータ損失の影響が大きい環境

FAQ / よくある質問

購入を決める前の疑問

NASがあればバックアップはいらない？

いいえ。RAID構成はHDDの一部故障に備える機能ですが、誤削除・災害・ランサムウェアなどには十分でない場合があります。別の復元用コピーを検討してください。

クラウドを使っていればデータが消えない？

クラウドであっても、権限設定・誤削除・同期・サービスの保持期間が問題になることがあります。復元できる履歴や独立したバックアップの有無を確かめます。

外付けHDDは会社のファイル共有に使える？

基本的には接続したPCの保存先です。複数人で安全に共有する用途には、別の共有方法やアクセス権限の設計が必要になります。

既にMicrosoft 365やGoogle Workspaceがある場合は？

まず契約内容を確認してください。既存の共有・容量・アクセス管理で足りるなら、新しいクラウドサービスの追加契約は不要かもしれません。

では、自分の場合は何が必要？

人数・用途・容量・アクセス環境から、比較すべき保存方法を整理します。購入前の確認事項と概算費用もまとめられます。
