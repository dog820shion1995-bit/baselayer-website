BASELAYER Visual Studio v5

機器のイラストを左のパレットからキャンバスにドラッグ＆ドロップできます。クリック追加にも対応。図の機器はドラッグで移動できます。「接続する」で2台を順にクリックすると線が引けます。
機器の名前・参考単価・Amazon検索キーワードを編集できます。PDFは「PDFに保存 / 印刷」からブラウザ印刷画面で「PDFに保存」を選択。JSON保存・読み込みにも対応。
GitHub Pagesには index.html, style.css, script.js, privacy.html をアップロードして同名ファイルを置き換えてください。
製品価格はサンプル値で、実際の見積ではありません。ネットワーク構成は概念図であり、実務の安全性や適合性を保証しません。Amazonは通常検索リンクで、アフィリエイト未設定です。
